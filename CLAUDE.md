# Hop-by-Hop

Публичный Telegram-бот с курсом по компьютерным сетям: от битов и Ethernet до TLS 1.3, современных прокси-протоколов (Xray, VLESS, REALITY, XHTTP, sing-box) и OpenWrt, с акцентом на информационную безопасность.

## Раскладка

Репозиторий лежит внутри рабочей папки; всё, что не публикуется, находится уровнем выше:

```
bot_network_education/          рабочая папка (не в git)
├── Books/                      купленные PDF, не публиковать
├── books_text/                 извлечённый текст книг (tools/extract_books.py)
├── ЗАПРОС.txt, ОТВЕТЫ.txt      исходный чат, личное
└── Hop-by-Hop/                 этот репозиторий (публичный)
    ├── docs/program.md         программа курса с привязкой к книгам
    └── tools/                  служебные скрипты
```

## Источники

- Олифер В., Олифер Н. "Компьютерные сети", 6-е изд.; Таненбаум Э. "Компьютерные сети", 6-е изд.; Ristić I. "Bulletproof TLS and PKI", 2nd ed.
- Текст книг для сверки: `../books_text/<slug>/toc.md` и `../books_text/<slug>/pages/NNNN.txt`. Номера страниц PDF совпадают с печатными (проверено для Олифера и Таненбаума).
- В старых уроках из чата (`../ОТВЕТЫ.txt`) есть ошибка: VLESS/VMess/Trojan/Shadowsocks - прокси потоков, а не туннель IP-пакетов.

## Правила контента

- Текст уроков пишется своими словами. Из книг берём структуру, модели и факты, даём ссылки "Олифер гл. X, с. Y", "Таненбаум разд. Z". Дословные цитаты - не длиннее одного предложения. Текст книг в репозиторий не попадает.
- Каждый факт сверяется с книгами; то, чего в книгах нет (Linux internals, netfilter, Xray/sing-box), - с первоисточниками: RFC, man, документация и исходники проектов.
- Команды из уроков должны реально выполняться (проверка в WSL Ubuntu или на VPS).
- Подача: сетевая инженерия и ИБ - как устроены протоколы и почему их трудно обнаружить. Без пошаговых инструкций по обходу блокировок и без ссылок на VPN-сервисы.
- Типографика: без кавычек-ёлочек (только "), без длинного тире (только -).
