# Журнал уроков

Каждый урок проходит конвейер: чтение источников → текст и иллюстрации → проверка команд на реальном Ubuntu → фактчек независимым агентом ([шаблон](factcheck-prompt.md)) → исправления → второй раунд фактчека → тесты → публикация в Telegraph → деплой.

| # | Урок | Telegraph | Что нашёл фактчек |
|---|---|---|---|
| 1 | Зачем нужна сеть | [ссылка](https://telegra.ph/Urok-1-Zachem-nuzhna-set-09-28) | TLS без аутентификации сервера; "оборудование только доставляет байты" противоречило бы уроку про NAT; сеть не гарантирует доставку (best effort); тест угадывался по длине вариантов |
| 2 | Биты, байты и шестнадцатеричная запись | [ссылка](https://telegra.ph/Urok-2-Bity-bajty-i-shestnadcaterichnaya-zapis-09-28) | "бит = два уровня сигнала" неверно для линии (многоуровневые коды, Олифер гл. 7); сетевой порядок байтов не всеобщий (WireGuard - little-endian); сценарий омоглифов уточнён; эталон вопроса требовал того, чего не было в тексте |
| 3 | Простейшая сеть из двух компьютеров | см. content/telegraph.json | ссылки на несуществующие блоки; кусок главы 2 (с. 61-73) выпадал из программы - перенесён в урок 4; RX/TX errors; порт - разъём без кабеля; рандомизация MAC; тест угадывался по длине |

## Изменения программы по ходу работы

- Урок 3: источник О 40-61; урок 4: добавлены О 61-73.
- Урок 16: в колонку ИБ добавлены port security и 802.1X.
- Урок 65: добавлены домены-двойники (IDN, xn--).
