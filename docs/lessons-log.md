# Журнал уроков

Каждый урок проходит конвейер: чтение источников → текст и иллюстрации → проверка команд на реальном Ubuntu → фактчек независимым агентом ([шаблон](factcheck-prompt.md)) → исправления → второй раунд фактчека → тесты → публикация в Telegraph → деплой.

|---|---|---|---|

## Изменения программы по ходу работы

- Урок 3: источник О 40-61; урок 4: добавлены О 61-73.
- Урок 16: в колонку ИБ добавлены port security и 802.1X.
- Урок 65: добавлены домены-двойники (IDN, xn--).
- Урок 6: источник О 107-127.

## Найдено и исправлено в инфраструктуре

- **Ссылки на страницы Олифера** в программе были номерами PDF, а не печатными (сдвиг -1..+3). Добавлен `tools/page_map.py`, все ссылки пересчитаны.
- **fail2ban на сервере бота видел не все неудачные входы по SSH**: в Ubuntu 24.04 служба называется `ssh.service`, а fail2ban по умолчанию смотрит `sshd.service`. Исправлено на сервере и в `deploy/bootstrap.sh`, проверено пробной попыткой. Угрозы не было: вход по паролю отключён.
- **Метка BOM** от PowerShell ломала загрузку уроков - вычищена, загрузчик сделан устойчивым к ней.
